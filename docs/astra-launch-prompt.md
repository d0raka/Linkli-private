## What Linkli is

Linkli (package name `linkli-saas`, origin https://linkli.online) is a Hebrew-first product for interactive invitation and surprise pages that people send on WhatsApp. It is NOT a link-in-bio tool and NOT a generic website builder.

The product promise: a host answers a few questions, gets a small interactive page, publishes it, and sends the link on WhatsApp. Guests open it on a phone, tap through a short experience, and (for events) RSVP.

Stack:
- Next.js 16.2 + React 19 + Vinext 0.0.50 on Cloudflare Workers
- D1 via binding `DB` (see `.openai/hosting.json` and `vite.config.ts`)
- Images binding `IMAGES` for Vinext optimization
- Resend for transactional email
- Launch checkout: PayPal hosted Checkout / Payment Links via `BILLING_PAYPAL_URL` (optional `BILLING_CHECKOUT_URL` fallback). Takbull / cards+bit later, optional. No Grow. No Stripe/Link.
- Custom HMAC webhook at POST `/api/billing/webhook` (tests) plus PayPal REST webhook at POST `/api/billing/webhook/paypal`
- Runtime schema is applied in `db/index.ts` (`ensureDatabase` + incremental migrators). Files in `drizzle/` are history, not the prod applicator.

- Plans and gating: `lib/plans.ts`
- Billing: `lib/billing.ts`, `app/api/billing/upgrade/route.ts`, `app/api/billing/webhook/route.ts`, `app/api/billing/portal/route.ts`, `app/api/billing/status/route.ts`
